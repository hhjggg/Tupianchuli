# 国补订单照片处理工具（Streamlit）

在浏览器中运行的图片处理工具：从单号表提取订单编号，在直供订单照片导出表中按
`三方单号 == 订单编号` 匹配对应照片，逐单显示、手动处理（旋转/翻转/缩放/裁剪/
调色/滤镜/二值化/水印等）并保存；同时支持一键把单号表「是否上传」列对应订单行
写入「是」。

直供订单表支持 **多文件导入**（1 个处理完成的文件 + 多个未处理的文件），自动按
「三方单号=16 位 且有照片」规则处理拼接，生成一个新文件后再匹配。

## 目录结构

```
deepseek/
├── app.py              # Streamlit 主程序（入口）
├── xlsx_reader.py      # 单号表解析、直供表流式解析 + 多文件合并 + 写入“是否上传”
├── image_tools.py      # 图片下载 + 图像处理（Pillow）
├── requirements.txt    # 依赖
├── README.md           # 本说明
├── export_images/      # 处理结果输出目录（本地运行时自动创建；默认保存到系统桌面）
├── .upload/            # 网页上传文件的本地副本（单号表写回处）
└── .photo_cache/       # 照片下载缓存
```

## 运行

```powershell
cd E:\py_code\deepseek
pip install -r requirements.txt
streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`。

## 使用流程

1. **选择数据表**：左侧选「使用本地文件」或「上传文件」。
   - 单号表：1 个
   - 直供订单表·**处理完成**：可选（没有可留空/不选）
   - 直供订单表·**未处理**：可多选多个（本地模式在文本框每行填一个路径）
2. 点击 **解析并匹配数据**（大表流式解析 + 自动合并生成新文件）。
3. 顶部查看统计：匹配且有照片 / 匹配无照片 / 未匹配订单（可展开核对），
   并可**下载生成的新文件**（合并直供订单表.xlsx）及各文件处理统计。
4. **逐单处理**：用「上一单/下一单」或下拉跳转，选择照片后用右侧工具处理，
   实时预览；点击 **保存当前图片** 默认输出到**系统桌面**（可在左侧栏
   「图片保存目录」修改），文件命名 `订单编号_照片序号.jpg`。
5. **标记已上传**：点击 **标记为已上传**，在单号表「是否上传」列、该订单编号
   所在行写入「是」并保存（上传方式可下载更新后的单号表）。

## 多文件合并规则

- 处理完成文件 + 所有未处理文件会统一处理拼接，**只保留「三方单号 = 16 位
  且 有照片」的行**，合并生成新文件 `合并直供订单表.xlsx`（可下载）。
- **处理完成文件是可选的**：若不存在，可直接只导入未处理文件，系统照常
  过滤拼接生成新文件。
- 处理完成的文件若已过滤过，再次过滤是幂等的，不影响结果。
- 匹配数据源 = 合并后的新文件。

## 匹配规则

- 单号表「订单编号」（16 位数字）== 直供表「三方单号」（16 位）。
- 直供表内 19/22 位三方单号不参与匹配；无照片订单与未匹配订单在页面单独列出。

## 常见问题

- **解析慢**：直供表 sheet1.xml 约 74MB，首次解析约 40~60 秒属正常，结果会缓存。
- **图片下载失败**：确认网络可访问照片链接；页面提供「重新下载本单照片」。
- **写入单号表失败**：检查单号表文件是否被其他程序占用。
